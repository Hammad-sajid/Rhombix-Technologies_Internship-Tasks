Testing (Rahul Shetty Academy Practice Site)

This project automates the Login and Forgot Password functionalities of
https://rahulshettyacademy.com/locatorspractice/

using Selenium WebDriver and TestNG framework.

⚙️ Tools & Technologies Used

Language: Java

Framework: Selenium WebDriver + TestNG

Build Tool: Maven

IDE: IntelliJ IDEA

🧩 Test Cases Automated

Login Test
Forgot Password

Clone the repository

git clone  https://github.com/Hammad-sajid/Rhombix-Technologies_Internship-Ta

testng.xml
